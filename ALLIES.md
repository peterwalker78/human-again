# Code for allies

Human Again is a handful of free apps that try to stay on the side of the people using them. If you make something in the same spirit, we are glad to point people to it.

Here is what that spirit means, in four plain promises. The thread running through all four: when what helps us and what helps the user pull apart, the user comes first.

## The four

1. **Honest and open.** It tells the truth about what it does, including where AI helped make it. The source is public under an open licence, so anyone can look. It can be free, take donations, or cost a one-off price, but no ads and no subscriptions.
2. **It stays on the user's computer.** Nothing is sent anywhere unless the user asks. No accounts, no tracking, no quiet phoning home. If something needs the internet, that is obvious, and it is the user's choice.
3. **Made to be put down.** No endless feeds, no autoplay the user did not pick, no streaks or points dangled to pull them back, and no nagging or guilt. It respects the user's time, and a day away costs them nothing. A game can still keep score; we only mean it is not built to hook them.
4. **A real tool, not an AI show.** AI can help build it, but the app itself does not make things for the user as they go, or send what they type off to a model. What the user sees was put there, and checked, by a person.

## It only gets stronger

We can make these promises tighter, never looser. Every change is public and dated. If a version waters them down, it is not this code, and cannot use the name. The strongest version that was ever true is the real one.

## Who can join

Most useful apps can: a timer, a reader, a notebook, a game, a tool for a real job. The one thing we ask is that yours is at least as plain-dealing as ours. In practice that means it runs on the user's own computer, works without a server behind it, keeps its words and pictures fixed rather than made up as it goes, and can be opened and checked.

If an app cannot really be checked, because it needs a live server or makes its content on the fly, we cannot vouch for it, however good it is. That is not a knock on the app. It is the limit of what we can honestly stand behind.

## How we check

Before we list an app, we read it and run it offline to see that it keeps the four, and we look again when it changes. If something is unclear, we sort it out in the open and say why. Anyone can flag a problem, with ours or an ally's app, on the [Report a problem](https://github.com/peterwalker78/human-again/issues/new?template=broken-promise.yml) form.

## If a promise breaks

If an app stops keeping the four, it comes off the list, and we say which promise and why. Fix it and you are welcome back. We are not out to catch anyone; the list just has to mean something.

## Joining

Open a [Join as an ally](https://github.com/peterwalker78/human-again/issues/new?template=join-as-ally.yml) issue: what the app is for, where its source is, and how it is made. We will take a look in the open, in the same thread.
